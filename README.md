Una app hecha con SwiftUI que te permite explorar los 8 planetas del sistema solar. La idea es simple: que cualquiera pueda abrir la app y aprender datos reales de cada planeta de forma visual y ordenada.

Puede servir para estudiantes que quieren repasar el sistema solar, para profesores que buscan una herramienta visual para sus clases, o simplemente para quien tenga curiosidad y quiera saber cuántas lunas tiene Saturno o por qué Venus es el planeta más caliente aunque no sea el más cercano al sol.

---

## Para que sirve la app

Esta app nacio con una idea clara: hacer que aprender sobre el sistema solar sea algo visual, rapido y sin tener que abrir un libro. No importa si eres estudiante, profesor o simplemente alguien curioso, la app te da informacion real sobre cada planeta de una forma que se entiende a la primera.

Puedes usarla para repasar antes de un examen, para mostrarle a alguien como funciona SwiftUI en un proyecto real, o simplemente para matar la curiosidad de saber cual es el planeta con mas lunas, cual tiene los vientos mas rapidos o por que Marte tiene el volcan mas alto del sistema solar.

No tiene datos inventados. Todo lo que muestra la app esta basado en informacion real de la NASA.
